# Blender Portfolio

A lightweight React + TypeScript portfolio focused on Blender artwork, environment design, and product visualization.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## GitHub Pages deployment

1. In GitHub, create a repository for the project.
2. Push this folder to the repository.
3. In the repository settings, enable GitHub Pages.
4. Set the source to the built static output from the `dist/` folder or use a GitHub Actions workflow.
5. Keep the project URL in the format:
   `https://<username>.github.io/<repo-name>/`

This project is intentionally simple and easy to maintain for free-tier hosting.
